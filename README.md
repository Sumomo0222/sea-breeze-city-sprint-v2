# 海风城市冲刺 · Sea Breeze City Sprint

一只小猫的 1000 米城市冲刺：从海边公路出发，爬上城市高架看一场日落，再冲进霓虹灯牌街区，越过 1000m 终点门。

**在线访问**

<https://sumomo0222.github.io/sea-breeze-city-sprint-v2/>

页面由 GitHub Pages 发布，经 GitHub 的 CDN 分发。曾经可用的 jsDelivr 镜像 `cdn.jsdelivr.net/gh/.../index.html` 现在会对 `.html` 文件返回 301 并跳到 GitHub 原始文件的纯文本地址，浏览器打开只会看到源码，所以这里不再列出。

## 玩法

- **换道**：← → 或 A D　**跳跃**：↑ / 空格 / W　**快速落地**：↓ / S　**暂停**：P / Esc　**静音**：M
- 手机：左右滑动换道，点按或上滑跳跃，下滑快速落地；也可以用屏幕角落的按钮
- 三条车道、三颗心。锥桶、保温箱、工具箱、垃圾桶可以跳过去，汽车必须换道躲避
- 金币每枚 10 分，跃过障碍另加 15 分，冲线有完赛奖励和时间奖励；全程不碰撞得三星
- 一趟约 60 秒。最好成绩按得分保存在浏览器本地

## 路线

| 里程 | 场景 | 天色 |
|---|---|---|
| 0 – 330 m | 海边公路：沙滩、棕榈、遮阳伞、帆船 | 白天 |
| 312 – 392 m | 上匝道，路面抬升 14 m | 傍晚 |
| 330 – 696 m | 城市高架：两侧楼宇、路灯、天台广告牌 | 日落 |
| 650 – 752 m | 下匝道回到地面 | 暮色 |
| 696 – 1000 m | 灯牌街区：临街商铺、成排的竖向霓虹招牌 | 夜晚 |

## 从指定里程起跑

在地址后加 `?from=700` 可以直接从 700 m 开始（范围 0 – 990），方便直接看某一段。这种起跑会标「练习起跑」，不计入纪录。

## 技术说明

- 纯静态单文件 `index.html`：无框架、无外部请求，Canvas 2D 手写伪 3D。
- **统一投影**：路面、护栏、金币、障碍、楼宇全部经过同一个投影函数
  `screenX = cx + f/dz · x`，`screenY = hy + f/dz · (镜头高度 − y)`，所以透视天然一致。
- **护栏**：取路缘外侧一个固定横向偏移的竖直面，近粗远细，和车道线一起收敛到同一个消失点，不会横穿画面。
- **不做横向色带**：路面没有深浅交替的横带，车道线是实线，路缘是单色。
- **防晕**：镜头不随步频起伏；换道时镜头只轻微跟随；速度线基本取消；系统开启「减少动态效果」时会进一步关闭受击抖动和速度线。
- **性能**：远处路面切片合并绘制，霓虹字预渲染成贴图，按窗口大小限制画布像素，帧率不足时自动降档。

## 源码与构建

`index.html` 是由 `src/` 拼接生成的，发布和分享用的就是它。改源码请改 `src/`，然后在此目录运行：

```sh
sh build.sh
```

只依赖 `sh` 和 `cat`。

```
src/
  00-head.html   文档头与 meta
  font.css       内嵌的字体子集
  style.css      界面样式
  10-body.html   界面结构
  js/01-core.js      投影基础、赛道几何、调色板、关卡生成
  js/02-camera.js    画布与镜头、可见切片、背景
  js/03-slices.js    路面 / 标线 / 护栏 / 桥体
  js/04-scenery.js   楼宇、商铺、棕榈、路灯、终点门
  js/05-items.js     金币、障碍、汽车
  js/05b-cat.js      小猫
  js/06-fx.js        特效与游戏规则
  js/07-audio.js     WebAudio 合成音效与配乐
  js/08-ui.js        界面、输入、主循环
```
